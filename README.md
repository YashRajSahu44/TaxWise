# TaxWise 💰

A clean, brutalist-styled income tax calculator based on India's **New Tax Regime (FY 2025-26)**. Enter your annual income and get an instant tax estimate.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black)

## ✨ Features

- Calculates tax instantly based on the New Regime slab rates
- Slab rates displayed upfront so users know how the number is derived
- Input validation for empty or invalid amounts
- Indian-format currency output (e.g. ₹1,52,000)
- Fully responsive, single-page design — no frameworks, no dependencies

## 📊 Tax Slabs Used (New Regime, FY 2025-26)

| Annual Income       | Tax Rate |
|---------------------|----------|
| Up to ₹12,00,000    | Nil      |
| ₹12,00,001 – ₹16,00,000 | 15%  |
| ₹16,00,001 – ₹20,00,000 | 20%  |
| ₹20,00,001 – ₹24,00,000 | 25%  |
| Above ₹24,00,000    | 30%      |

> Note: This is an estimate for educational purposes and does not account for cess, surcharge, or rebates (e.g. Section 87A).

## 🛠️ Tech Stack

- HTML5
- CSS3 (custom properties, flexbox, responsive design)
- Vanilla JavaScript (DOM manipulation, form handling)
